## About Me

Software Engineering graduate from **FPT University** (April 2026), focused on **backend development with C# and ASP.NET Core**. I like backends where the hard part is the *logic* — concurrency, consistency, auth — not the number of endpoints.

- **Building now:** [**Mercato**](https://github.com/QuanHT2412/Mercato), an e-commerce backend of three .NET 10 microservices behind a YARP gateway, plus **DocQA**, a question-answering API over documents using retrieval-augmented generation (ASP.NET Core, PostgreSQL + pgvector).
- **Experience:** Backend Intern at **FPT Software** (08/2024 – 12/2024, Java / Spring Boot e-commerce platform); backend developer on a warehouse-management graduation project (09/2025 – 01/2026).
- **Looking for:** fresher backend roles in **.NET or Java**. Longer term: deep backend + AI integration.
- **Reach me:** [hoangthienquan5000@gmail.com](mailto:hoangthienquan5000@gmail.com)
